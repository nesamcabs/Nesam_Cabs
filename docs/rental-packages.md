# Hourly rental packages

All three customer websites and admin bookings accept every whole duration from 1 to 15 hours.

In Admin > Pricing > Brand & service fares, choose All brands or a brand, Hourly Rental, and the vehicle class. Set the first-hour customer fare, additional-hour fare, hourly partner payout, included kilometres, extra kilometre rate, and extra-hour rate. Choose kilometres per hour or a fixed allowance per trip.

Generate 1?15-hour packages, review or edit each package row, then Save with a reason. Generation changes the form only; Save publishes it. Existing hourly rates prefill matching fields where available. Enter the missing values yourself. No production prices were invented or changed by this update.

A package without a configured fare remains unavailable until an administrator saves it. Existing bookings retain their original fare snapshots.
